# Dual-lens fixtures

Synthetic, generated by `make.sh` with ffmpeg lavfi sources. No camera
recording and no vendor artefact is stored here.

The clip imitates what the measured PROVIEW IPC sends: one H.264 stream whose frame
holds two 16:9 pictures stacked vertically.

| File | What it is |
|---|---|
| `dual-lens-stacked-640x720.h264` | Annex-B clip, 640x720 = two 640x360 halves, 10 fps, 2 s |
| `dual-lens-stacked-640x720.mp4` | the same content as fragmented MP4, playable in a browser |
| `hevc-1920x1080.sps` | one HEVC sequence parameter set (43 bytes) for the frame-size parser test |

The halves are visually distinct on purpose:

- top half `#203040` with a static `#E0C040` block: the fixed lens.
- bottom half `#304020` with a white block that travels left to right: the lens that moves.

That makes a crop testable by eye: if the moving block shows up in the top crop, the
crop arithmetic is wrong.

Regenerate with `./make.sh` (needs ffmpeg with libx264 and libx265, plus python3).
